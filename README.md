# Welingo - AI Assisted Language Learning Platform

Welingo is an AI-assisted language learning platform designed specifically for learners of Chinese. Our goal is to provide an immersive and personalized learning experience for students of all levels. By leveraging advanced AI technology, Welingo tailors lessons, exercises, and feedback to each user's needs, making language learning more efficient and engaging.

## Features

- **Personalized Learning Path:** Welingo uses AI to adapt lessons and activities to your learning speed and preferences, ensuring that you are always challenged without feeling overwhelmed.
- **Chinese Language Focus:** Specifically designed for learning Chinese, with an emphasis on grammar, vocabulary, pronunciation, and cultural nuances.
- **Integration with Zhejiang Normal University Curriculum:** Our curriculum is aligned with the language courses offered to international students at Zhejiang Normal University, ensuring that the content is up-to-date and relevant to real-world Chinese language education.
- **AI-Driven Feedback:** Receive real-time feedback on pronunciation, grammar, and sentence structure with the help of advanced speech recognition and natural language processing.
- **Progress Tracking:** Keep track of your learning milestones and achievements, with visual insights into your improvement over time.

## Tools and Technologies

- **Flutter:** Used for building a cross-platform mobile app that provides a smooth, responsive user interface on both Android and iOS.
- **Dubao API:** We integrate with the Dubao API to offer intelligent, natural language learning features such as speech recognition, sentence analysis, and real-time feedback.
- **Zhejiang Normal University Curriculum:** The app’s content is based on the curriculum designed for international students studying Chinese at Zhejiang Normal University, which ensures the highest educational quality and relevance.

## Developer Resources

### Prerequisites

- Flutter SDK (version >= 3.0)
- Dart SDK (version >= 3.0)
- Access to Dubao API (create an account and get your API key)

### Setup

1. Clone the repository:
    ```bash
    git clone https://github.com/DeepDevClub/welingo.git
    cd welingo
    ```

2. Install Flutter dependencies:
    ```bash
    flutter pub get
    ```

3. Configure the Dubao API key:
    - Create a `.env` file in the root directory.
    - Add your Dubao API key:
    ```bash
    DUBAO_API_KEY=your_api_key
    ```

4. Run the app:
    ```bash
    flutter run
    ```
